# Full-Stack Blog Application

A responsive, feature-rich blogging platform that allows users to create, edit, publish, and manage blog posts with full CRUD capabilities. Built with React, Tailwind CSS, and Appwrite Backend-as-a-Service, the platform integrates rich-text editing, dynamic routing, and centralized state management[cite: 1].

---

### About the Project

This application provides a complete blogging solution focusing on content formatting, media storage, and clean URL navigation[cite: 1].

**Key Features:**
* **Full CRUD Operations:** Seamlessly write, edit, publish, and delete blog articles[cite: 1].
* **Authentication & Sessions:** Secure user registration, login, logout, and session lifecycle handling managed by Appwrite Auth[cite: 1].
* **Rich-Text Editing:** Embedded TinyMCE editor for formatting blog content[cite: 1].
* **Media Management:** Integrated Appwrite Storage for uploading and serving post featured images[cite: 1].
* **Centralized State:** Powered by Redux Toolkit for authentication and post state tracking[cite: 1].
* **SEO-Friendly Navigation:** Dynamic slug-based routing powered by React Router[cite: 1].

**Tech Stack:**
* **Frontend:** React.js, Tailwind CSS[cite: 1]
* **State Management:** Redux Toolkit[cite: 1]
* **Routing:** React Router[cite: 1]
* **Backend-as-a-Service:** Appwrite (Auth, Database, Storage)[cite: 1]
* **Editor:** TinyMCE[cite: 1]
